# Smith homepage prototype

Interactive prototype of the Smith Electronics homepage, with a link to the Smith Solar site.
Built by Isadora Agency. For internal review only — not the production site.

Live preview: https://<account-name>.github.io/smith-prototype/

Plain HTML, CSS and JavaScript (GSAP + Lenis); no build step.
To run it locally, serve the folder:

    python3 -m http.server 8000
